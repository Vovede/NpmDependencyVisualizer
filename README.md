# NpmDependencyVisualizer

Инструмент для получения и визуализации графа зависимостей npm-пакетов.

## Возможности

- Получение прямых зависимостей пакетов из npm Registry.
- Построение графа транзитивных зависимостей с помощью алгоритма DFS.
- Ограничение глубины построения графа.
- Фильтрация зависимостей по подстроке.
- Обнаружение циклических зависимостей.
- Вывод порядка загрузки зависимостей.
- Поддержка диапазонов версий npm.
- Экспорт графа в формат D2 и создание PNG-диаграммы.
- Работа с тестовым репозиторием.

## Технологии

- Python 3.12
- PyYAML
- Requests
- semantic-version
- pytest
- D2

## Установка

1. Склонируйте репозиторий:

```bash
git clone https://github.com/Vovede/NpmDependencyVisualizer
cd NpmDependencyVisualizer
```

2. Установите зависимости Python:

```bash
pip install -r requirements.txt
```

3. Отдельно установите язык D2

## Запуск

Перед запуском укажите интерпретатору Python на директорию исходных файлов

```powershell
$env:PYTHONPATH="src"
```

Запуск по умолчанию:

```powershell
python -m visualizer.main
```

Запуск с конфигурацией (параметр `--config`):

```powershell
python -m visualizer.main --config <путь к файлу конфигурации>
```

Запуск с выводом порядка загрузки зависимостей (параметр `--loading-order`)

```powershell
python -m visualizer.main --loading-order
```

Результаты визуализации сохраняются в папке `output`.

## Конфигурация

Параметры задаются в YAML-файлах каталога `config`:

| Параметр | Назначение |
|---|---|
| `package_name` | Имя npm-пакета |
| `repository` | URL npm Registry или путь к тестовому репозиторию |
| `test_mode` | Режим работы с тестовым репозиторием |
| `version` | Версия пакета |
| `output_file` | Имя выходного PNG-файла |
| `max_depth` | Максимальная глубина обхода графа |
| `filter_substring` | Подстрока для фильтрации зависимостей |

## Тестирование

Для запуска автоматических тестов выполните:

```powershell
pytest -v
```
